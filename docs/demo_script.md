# 现场演示脚本（约7分钟）

演示前：配置自己的 .env，确认账户余额及网络；先运行真实API评估并查看 results/live_summary.json。启动 app.py，投影浏览器、放大到120%~150%，确认没有其他服务占用7860端口。不要将Key、.env或终端环境变量投屏。所有设备始终称为“模拟设备”。

| 时段 | 操作 | 讲解与检查 |
|---|---|---|
| 0:00–0:45 | 展示标题、右侧四类设备、下方日志；点击重置 | 本项目使用真实DeepSeek进行工具选择，LangGraph负责流程，设备均为本地模拟 |
| 0:45–1:20 | 输入“你好” | 闲聊无需工具，设备状态不变；展示本次路径未进入工具节点 |
| 1:20–2:10 | 输入“关闭客厅灯”，再输入“把卧室灯亮度设置为30%” | 展示灯光工具、参数、Observation与右侧开关/30%状态对应 |
| 2:10–3:20 | 输入“我要睡觉了，关掉灯、锁好门，明早7点叫我” | 展示同一指令选择灯光、门锁、闹钟三个工具；闹钟为明天07:00北京时间，状态只保存记录 |
| 3:20–4:00 | 输入“现在家里的设备是什么状态” | 查询工具读取快照；展示当前全部设备，解释不是固定调用所有工具 |
| 4:00–5:00 | 输入“把门打开”，先不要确认，再点击“确认模拟解锁” | 第一次门锁仍已锁定、confirmation_required；第二次才解锁，确认有效期120秒。不是物理开门 |
| 5:00–5:50 | 输入“设置闹钟”确认会提问，再输入“设置明天早上8点的闹钟” | 模型不能编造时间，展示参数校验和时区；闹钟不后台响铃 |
| 5:50–6:30 | 输入“取消闹钟”两次；再“播放轻音乐”“暂停音乐” | 首次取消成功，第二次not_found，不虚报成功；音乐仅状态变化，不产生音频 |
| 6:30–7:10 | 展开完整日志，导出JSON或CSV；展示工作流PNG | 日志有时间、用户输入、工具名、参数、结果、状态；只展示公开行动说明，不含内部思维链 |

若模型响应慢：等待返回，避免重复点击；30秒超时会明确失败。若现场网络不可用：坦诚说明真实API暂不可用，可展示先前真实联调日志（仅在确实运行过时），再运行离线测试解释工具和图逻辑。不得把预设消息测试称为真实模型运行，不生成假截图。报告的现场截图应现场运行保存。
